# Stroke Rush

A rhythm rowing endless runner. Row through a flooded city in time with the beat and outrun the Cox Cop.

**Play / install:** https://appleboyofficial.github.io/stroke-rush/

On iPhone: open the link in Safari → Share → **Add to Home Screen**. It runs full screen and works offline.

## Controls
- Tap left / right half of the screen, alternating, on the beat to row
- Swipe ← → to change lanes, ↑ to jump, ↓ to duck
- Keyboard: Z / X to row, arrow keys to move
